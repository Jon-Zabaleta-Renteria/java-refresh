# java-refresh

Repositorio de estudio: un repaso de Java desde los fundamentos, siguiendo
*Programación orientada a objetos con Java usando BlueJ* (Barnes y Kölling, 6ª ed.).

## Por qué empezar por el principio

Podría haber saltado directamente a un framework o a un IDE potente. He
preferido hacer lo contrario: volver a un libro de iniciación y a BlueJ, un
entorno pensado para aprender, donde no hay nada entre el código y los objetos.

El motivo es sencillo: con el tiempo, uno acumula cosas que sabe *usar* sin
llegar a *entender* del todo. Funcionan, pero no sabría explicar por qué. Este
repaso es para encontrar esos huecos y cerrarlos, aunque eso signifique
detenerme en conceptos que en teoría ya conozco.

## Cómo trabajo

- **Todos los ejercicios**, también los que parecen triviales. Los huecos
  suelen esconderse justo ahí.
- **Predecir antes de ejecutar.** Antes de probar algo, intento anticipar qué
  va a pasar. Si me equivoco, ahí hay algo que no había entendido.
- **Romper el código a propósito** para ver qué error da y por qué.
- **Explicar con mis palabras.** Los comentarios del código son mis notas, no
  una copia del libro.

## Estructura

Cada carpeta corresponde a un proyecto del libro. El primer commit contiene
los proyectos originales, así que cualquier diferencia posterior es trabajo mío.

## Git

Este repositorio también es mi práctica de Git. Trabajo desde la terminal,
sin interfaces gráficas, para aprender los comandos de verdad: preparar
cambios, hacer commits con mensajes que expliquen qué he hecho y mantener
el historial ordenado. Que el código esté aquí es casi secundario; el hábito
es lo que quiero que se quede.
